# shortcut-lens

Finds the hidden failure groups ("slices") of an image classifier without group labels, names them
in plain English, checks the named cause with counterfactual edits, and fixes the failures with
last-layer retraining — validated against shortcuts we plant ourselves.

**Status:** in development. Results, demo and quickstart arrive in milestone M8.
